# Contributing

Thanks for helping keep this list accurate.

## What to add

- Free or freemium **HTTP APIs** for LLMs (chat, embeddings, speech→text, etc.)
- Clear signup / docs links
- Honest notes: rate limits, card required?, production restrictions

## What not to add

- Paid-only APIs with no free path
- Affiliate spam or unpaid “sponsored” placements
- Closed Discord-only / invite-only services without a public API page
- Tools that are only GUIs with no callable API

## PR checklist

1. Add the entry in the right section of `README.md`
2. Prefer official docs links over third-party blogs
3. Note the date you last verified limits (in the PR description)
4. Keep alphabetical order within a section when practical
5. One provider per PR when possible (easier to review)

## Format

```md
| **Name** | Free highlight | Card? | Notes | [Docs](https://...) |
```
